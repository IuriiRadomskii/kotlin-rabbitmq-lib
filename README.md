# RabbitMQ Client

## Описание проекта
Клиентская библиотека для работы с RabbitMQ на Kotlin.

## Пакеты
- **resources** - управление соединениями и каналами (connection pool, channel pool)
- **publisher** - публикация сообщений
- **consumer** - потребление сообщений
- **serialization** - сериализация/десериализация
- **model** - модели данных: модели обертки дто из библиотеки rabbitmq, класс с метаданными
- **config** - конфигурационные классы для настройки паблишера, консьюмера и ресурсов

## Технологический стек
- Kotlin 2.2
- Java 21
- Gradle
- RabbitMQ Client Library
